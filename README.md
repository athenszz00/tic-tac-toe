# Tic-Tac-Toe

A two-player Tic-Tac-Toe game built with Next.js, React 19, Tailwind CSS, and shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play. Players take turns placing X and O; the game announces a winner or draw. Select **New game** to reset the board.

## Deploy on Vercel

Import this project into [Vercel](https://vercel.com/new) and deploy with the default Next.js settings, or deploy from a terminal with the Vercel CLI:

```bash
npx vercel
npx vercel --prod
```
